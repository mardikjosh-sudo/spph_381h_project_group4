# Reproducibility Note

The analysis uses the committed public CSV snapshot at `data/SubstanceHarmsData.csv` (SHA-256 `b9f014cedb78acfcee2b6307ff42aea6fa5116c61150af304d677f26faff14fa`). The report reads it with repository-relative paths; it does not query the live PHAC site during rendering. The source and technical notes are linked in the report.

From the repository root in a Codespace or a local environment with Quarto, R, and the R packages `readr`, `dplyr`, `tidyr`, `knitr`, and `ggplot2`, run:

```sh
quarto render milestones/m3-project-update/submission/report-draft.qmd
```

The command writes `report-draft.html` beside the QMD and regenerates `outputs/table1.csv` and `outputs/missingness-summary.csv`. Table 1 uses the common 2016–2024 window, excludes partial-year Nunavut 2023, and shows the contributing-year count for each region and measure. The figures and tables in the report are generated by the QMD, and the HTML embeds the figures for standalone viewing. The source code checks that the selected data form 140 unique region-years across 14 regions and that unexpected missing-value labels are absent.
